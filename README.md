### Dev

The site uses pnpm and vite. Use `pnpm dev` to start a development server.

### Puzzles for Ninja Chess

You can download and use the Lichess puzzles exports as source for the puzzle sample. Run `pnpm puzzle` to generate a new sample.

Lichess exports are found at https://database.lichess.org/#puzzles

### Deploy

See the GitHub pages section here : https://vite.dev/guide/static-deploy
